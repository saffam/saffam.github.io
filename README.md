    <h2>Projects</h2>

    <h3>European Food Policy & Obesity Analysis</h3>

    <p>
        This project examines the relationship between food-policy characteristics
        and adult obesity prevalence across 27 European countries using publicly
        available data.
    </p>

    <p>
        The analysis combines country-level obesity prevalence data with indicators
        describing food-policy activity and policy instrument diversity. I used
        Python and OLS regression to explore cross-country associations and
        conducted model diagnostics, including residual and influence analysis.
    </p>

    <p>
        The final model explained 19.7% of the variation in obesity prevalence
        (R² = 0.1965; adjusted R² = 0.1296). The overall model p-value was 0.0724,
        so the findings are presented as exploratory associations rather than
        evidence of a causal relationship.
    </p>

    <p>
        The project includes data documentation, regression outputs, diagnostic
        results, and visualizations to make the analysis transparent and
        reproducible.
    </p>

    <p>
        <strong>Tools:</strong> Python, pandas, statsmodels, matplotlib,
        regression analysis, data visualization.
